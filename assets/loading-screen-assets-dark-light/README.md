# Loading Screen Assets

8-bit / pixel-art loading screen assets for the Data Professional portfolio.

## Themes
- dark/: night/ocean/neon loading screen assets
- light/: day/sky/pastel loading screen assets
- ui/: reserved for future extracted UI elements

## Main assets
- background_dark.png / background_light.png
- loading_box_dark.png / loading_box_light.png
- loading_box_variations_dark.png / loading_box_variations_light.png
- cloud, sky, floating-island and water assets for both themes

The original generated sheet is included as master_asset_sheet.png.
