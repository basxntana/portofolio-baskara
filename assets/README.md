# Baskara — 8-bit Portfolio Asset Pack

Assets prepared for the retro-tech / pixel-art portfolio concept.

## Structure

- `reference/portfolio-mockup.png` — full visual reference
- `images/` — extracted visual references/crops from the mockup
- `icons/` — reusable SVG icons
- `styles/palette.css` — design tokens and colors
- `styles/pixel-ui.css` — basic pixel UI helpers

## Core palette

- Background: `#0D1117`
- Primary: `#39FF88`
- Secondary: `#5B8CFF`
- Accent: `#FFD166`
- Text: `#E6EDF3`
- Muted: `#7D8590`

## Notes

The image crops are visual reference assets from the generated concept. For production,
replace them with final-purpose pixel art/sprites where needed. The pack intentionally
does not bundle third-party font files; use a properly licensed web font such as
Pixelify Sans / Press Start 2P and a modern body font.

Recommended project folders:

`public/assets/images`
`public/assets/icons`
`src/styles`
