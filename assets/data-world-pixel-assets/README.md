# Data World — Pixel Asset Pack

Generated to match the 8-bit / pixel-art portfolio visual direction.

## Contents

- `asset_sheet_master.png` — full modular reference sheet.
- `background/` — night ocean background, sky variations, clouds.
- `cities/` — three themed city/island scenes plus a combined hub.
- `buildings/` — modular building pieces for Data Engineering, Analytics, and Science.
- `nature/` — trees and environmental pieces.
- `water/` — water/waterfall assets.
- `bridges/` — bridges and path pieces.
- `tiles/` — floating island terrain tiles.

## Recommended web usage

Use `night_ocean_background.png` as the base layer, then place:
1. small islands / clouds,
2. city islands,
3. bridges,
4. decorative buildings,
5. foreground UI.

For a production website, the three city scenes can be further separated into
transparent PNG layers so the buildings, trees, islands, and bridges can animate independently.
