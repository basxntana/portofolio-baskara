# Data World separated assets

Separated from the Data World visual reference.

## Structure
- dark/background.png — dark/night background (opaque)
- light/background.png — light/day background (opaque)
- dark/islands/ — three floating island assets with transparent background
- light/islands/ — three floating island assets with transparent background
- dark/frames/ — label/title/button/tip UI assets with transparent background
- light/frames/ — label/title/button/tip UI assets with transparent background

The background images are intentionally opaque. Islands and UI elements are exported as RGBA PNGs so they can be layered in the website.
