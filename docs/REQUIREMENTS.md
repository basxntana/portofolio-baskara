**Portfolio Website Requirements**

1\. Project Overview

Membangun website portfolio pribadi dengan konsep **8-bit / pixel-art
retro-tech** yang merepresentasikan perjalanan dan kemampuan sebagai
**Data Professional**.\
Website akan menampilkan tiga bidang utama:

- **Data Engineering**

- **Data Analytics**

- **Data Science**

Konsep visual:

**8-Bit RPG × Data × Technology**\
Website harus terasa seperti sebuah dunia digital yang dapat dijelajahi,
tetapi tetap memiliki struktur dan informasi yang profesional untuk
kebutuhan portfolio dan recruitment.

**2. Main Objective**

Website bertujuan untuk:

1.  Memperkenalkan profil profesional.

2.  Menunjukkan kemampuan dalam Data Engineering, Data Analytics, dan
    Data Science.

3.  Menampilkan project yang pernah dikerjakan.

4.  Menjelaskan proses dan kontribusi pada setiap project.

5.  Menampilkan technology stack.

6.  Menunjukkan perkembangan skill.

7.  Menyediakan akses ke GitHub, LinkedIn, dan kontak.

8.  Menjadi personal branding yang berbeda dari portfolio data pada
    umumnya.

**3. Personal Branding**

Primary Identity

    BASKARA KRESNA

    DATA PROFESSIONAL

    Data Engineering · Data Analytics · Data Science

Website tidak memposisikan pengguna hanya sebagai Data Engineer,
Analyst, atau Scientist.\
Ketiga bidang tersebut merupakan bagian dari kemampuan utama pengguna
dalam mengolah data dari awal hingga menghasilkan insight atau model.

**36. Design Principle**

Website harus mengikuti tiga prinsip utama.

**Professional**

Recruiter tetap dapat memahami informasi dengan cepat.

**Interactive**

Website terasa seperti portfolio yang dapat dieksplorasi.

**Personal**

Konsep 8-bit menjadi identitas personal, bukan sekadar dekorasi.

**37. Definition of Done**

Website dianggap selesai apabila:

- Website dapat diakses secara online.

- Responsive pada desktop dan mobile.

- Tiga bidang utama ditampilkan dengan jelas.

- Project dapat difilter berdasarkan bidang.

- Project memiliki detail yang jelas.

- GitHub dapat diakses.

- Tidak ada broken link.

- Tidak ada console error.

- Performance baik.

- SEO dasar tersedia.

- Visual 8-bit konsisten.

- Informasi tetap mudah dibaca.

- Website terlihat profesional untuk kebutuhan recruitment.
